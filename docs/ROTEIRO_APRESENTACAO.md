# Apresentação — 10 minutos

| Tempo | Demonstração |
|---|---|
| 0:00–1:00 | Tema, exemplar físico, objetivo e participação individual real |
| 1:00–2:00 | Diagrama, MVC, Eloquent e responsabilidades de Services |
| 2:00–3:00 | Login admin, bibliotecário e consulta; mostrar bloqueio de escrita |
| 3:00–4:30 | Cadastrar/editar livro, categoria, pesquisa e ficha |
| 4:30–5:30 | Registrar empréstimo, leitor vê somente o seu, devolver |
| 5:30–6:30 | API GET e POST autenticados, Resource, erro 422/403 |
| 6:30–8:00 | SQL: dois índices, duas functions, CALL das duas procedures; auditoria automática |
| 8:00–9:00 | Testes web/API/PostgreSQL e evidências de backup/restauração |
| 9:00–10:00 | Git, decisões, limitações verificadas e conclusão |

Prepare antes: servidor, assets, banco de demonstração isolado com seed, token em variável e terminal sem senhas visíveis. Não execute migrate:fresh durante a apresentação no banco real. Consulte TESTES.md para resultados reais e pendências. Confirme com o professor a autorização da entrega individual, pois o resumo do enunciado indica grupos de 3 a 4. Não há prazo de entrega confirmado neste repositório.
